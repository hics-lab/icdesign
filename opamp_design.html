5T OTA 설계 실습 — 사용법

무엇을 하는 페이지인가

5-트랜지스터 OTA(차동쌍 M1/M2 + 전류거울 부하 M3/M4 + 꼬리 전류원 M5)를 직접 사이징하면서, 손계산(제곱법칙)과 SPICE(ETRI BSIM3v3 + ngspice) 결과를 나란히 비교합니다. 손계산은 슬라이더를 움직이는 즉시, SPICE 는 약 0.3 초 뒤 브라우저 안에서 계산됩니다 (서버 전송 없음).

  • 왼쪽 카드 (핵심 성능): 큰 파란 글씨 = SPICE, 주황 글씨 = 손계산. 왼쪽 테두리가 초록이면 충분, 빨강이면 문제입니다. 카드를 누르면 관련 그래프와 수식이 열리고 그 수식이 노랗게 깜빡입니다.
  • 회로: 노드 전압과 전류, 소자별 동작 영역(초록 포화 / 빨강 선형). 소자를 누르면 동작점 표가 열립니다. 설계 변수 묶음(예: M1/M2)에 마우스를 올리면 회로도에서 그 소자가 주황 테두리로 표시됩니다.
  • 그래프: Bode(개루프), ICMR(단위이득 버퍼로 Vin 스윕), 차동 전달 특성(Vout–Vid).
  • 아래 탭: 💡 진단(지금 설계의 문제와 해 볼 것 — 빨간 숫자 = 문제 개수), 📊 성능 비교 표(차이가 크면 빨강), 🔍 동작점 표, 📐 수식(현재 값 대입), 🧮 손계산 모델 파라미터.
  • PC 화면에서는 페이지 전체가 한 화면에 들어가고, 내용이 넘치는 칸만 따로 스크롤됩니다. 폰에서는 카드가 위쪽에 가로로 놓입니다 (밀어서 넘김).
  • 🧭 설계 도우미: 사양(GBW, SR, CL, ICMR)을 넣으면 표준 순서로 W/L 을 계산해 적용합니다.
  • 🔗 SPICE 실습 페이지: 현재 설계를 netlist 로 만들어 SPICE 실습 페이지에서 엽니다 (.ac / .dc / .noise 포함).

회로 연결

M1 게이트 = V+(비반전), M2 게이트 = V−(반전). 전류거울의 다이오드(M3)는 M1 쪽, 출력은 M2/M4 드레인. NMOS 입력형은 M3/M4 가 PMOS(VDD 쪽), M5 가 NMOS(접지 쪽)이고, PMOS 입력형은 위아래가 뒤집힌 구조입니다. 기판(bulk)은 NMOS → 접지, PMOS → VDD. 드레인/소스 면적은 AD=AS=W×0.5µm, PD=PS=W+1µm 로 넣습니다.

손계산 모델 (Level 1)

  • 포화: ID = ½·k'·(W/L)·Vov²·(1+λVDS), 선형: ID = k'(W/L)(VovVDS − VDS²/2)(1+λVDS).
  • λ(L) = λ@1µm × 1µm/L — 채널을 길게 하면 출력저항이 커지는 효과를 반영 (예전 버전은 λ 가 L 과 무관해서 L 을 바꿔도 이득이 그대로였음).
  • body effect: VTH = VT0 + γ(√(2φF+VSB) − √2φF). 입력쌍의 소스(꼬리 노드)가 접지보다 높아서 VTH 가 0.3~0.4 V 커집니다.
  • 파라미터는 ETRI BSIM3v3(TT)을 ngspice 로 돌려 W=20µm, |VDS|=2.5V, Vov 0.15~0.45V 구간을 제곱법칙으로 피팅한 값입니다: k'n≈115, k'p≈38.6 µA/V², VTN≈0.72, |VTP|≈0.96 V, λn≈0.027, λp≈0.053 V⁻¹ (L=1µm), γn≈0.70, γp≈0.50.

손계산과 SPICE 가 다른 이유

  • λ 의 L 의존성: 실제 BSIM3 의 출력저항은 1/L 보다 빨리 커집니다 (λn: L=1→2µm 에서 0.027→0.0053). 그래서 L 이 길수록 손계산 이득이 SPICE 보다 작게 나옵니다.
  • Vov 가 작을 때 (≲0.1 V): 약반전에 가까워 제곱법칙이 맞지 않습니다. gm/ID 는 실제로 약 25 V⁻¹ 를 넘지 못하는데 제곱법칙(2/Vov)은 무한히 커집니다.
  • Vov 가 클 때 / L 이 짧을 때: 이동도 저하·속도 포화로 실제 전류가 제곱법칙보다 작습니다.
  • 기생 커패시턴스: 손계산 미러 극점은 Cgs3+Cgs4 만 쓰지만 SPICE 는 접합·오버랩 용량을 모두 포함합니다.

측정 정의

  • A0: 1 Hz 에서의 개루프 이득. GBW: |H| = 0 dB 주파수. PM = 180° + ∠H(GBW).
  • ICMR (SPICE): 단위이득 버퍼에서 |Vout − Vin| ≤ 20 mV 인 Vin 범위. 손계산: Vov5+VGS1 ~ VDD−VSG3+VTN1 (NMOS 입력).
  • 선형 출력 범위 (SPICE): 차동 전달 곡선의 기울기가 최대의 50% 이상인 Vout 구간. 손계산: M2·M4 가 포화를 유지하는 구간.
  • SR = ISS/CL, 소비전력 = VDD·ISS (정지 상태).

설계 도우미의 순서 (NMOS 입력)

  1. ISS = SR · CL × (1 + 설계 여유)
  2. ICMR 최대 → Vov3,max = VDD − Vicm,max − |VTP| + VTN, Vov3 = min(Vov3,max, Vov 상한) → (W/L)3 = ISS / (k'p Vov3²)
  3. GBW → gm1 = 2π·GBW·CL × (1 + 설계 여유) → (W/L)1 = gm1² / (k'n ISS)
  4. ICMR 최소 → VDS5,sat = Vicm,min − VTN − Vov1, Vov5 = min(VDS5,sat, Vov 상한) → (W/L)5 = 2ISS / (k'n Vov5²)
  5. Vb = VTN + Vov5 (W 를 반올림한 뒤 다시 계산)

ICMR 이 허락하는 최대 Vov 를 그대로 쓰면 W/L 이 아주 작아지고(최소 폭 근처) 여유가 없어집니다. 폭이 좁은 소자는 실효 폭이 줄어(Weff ≈ W − 0.4 µm) SPICE 전류가 손계산보다 작게 나오므로, Vov 상한(기본 0.3 V)으로 여유를 둡니다. 같은 이유로 손계산은 ISS·gm 을 실제보다 10~25% 크게 예측하는 경향이 있어 설계 여유(기본 25%)만큼 키워서 설계합니다 — 적용 뒤 성능 표의 '목표' 열(SPICE 기준)로 확인하세요.

PMOS 입력형은 위아래(전압 = VDD − 전압)와 NMOS/PMOS 파라미터를 바꿔 같은 순서로 계산합니다.
